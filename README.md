
# My Survey Guard

**Version:** 2.0 Professional Edition

A browser-based survey history and duplicate detection tool.

## Features
- Survey History
- Duplicate Survey Detection
- Similarity Detection
- Configurable Lock Duration
- Blocked History
- GitHub Blocklist Integration
- JSON Backup and Restore
- CSV History Export
- Protection Enable / Disable

## Blocklist
Blocklist data is stored in `blocklist.json`.
